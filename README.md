# 맘별 AI 자기이해 미니리포트 (Mombyeol AI Self Insight Report)

✨ **40~70세를 위한 따뜻하고 우아한 AI 자기이해 리포트 웹 애플리케이션**

## 🌟 주요 기능
1. **시니어 친화적 접근성 디자인**:
   - 맑고 차분한 라이트 크림(`#FAF8F5`)과 딥 네이비(`#1B2A4A`) 컬러 시스템.
   - 글자 크기 실시간 조절 시스템 (**보통**, **크게**, **더크게** +55% 확대).
2. **12가지 심층 진단 & 4원소 분석**:
   - 현재 감정 날씨, 충전율 배터리 게이지, 내면의 3대 핵심 강점, 관계 소통 패턴 및 I-Message 솔루션, 오늘 시작하는 3가지 실천 제안.
3. **수호 캐릭터 가이드**:
   - **AI 클레어 (Claire)**: 따뜻한 조언과 질문 길잡이.
   - **포포 (Popo)**: 별빛 수호 배지.
4. **15페이지 PDF 완전판 리포트 생성 및 다운로드**:
   - 4원소 차트, 심층 편지, 수료증이 포함된 A4 15페이지 PDF 다운로드 기능.

## 🛠️ 사용 기술
- **Frontend**: HTML5, Vanilla CSS3, Modern JavaScript (ES Modules)
- **Build Tool**: Vite
- **Libraries**: Chart.js, jsPDF, html2canvas
